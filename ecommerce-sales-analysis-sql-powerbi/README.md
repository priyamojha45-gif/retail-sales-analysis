# E-Commerce Sales Analysis — MySQL + Power BI

## Project overview
An end-to-end e-commerce sales analysis project using MySQL for data preparation and analysis, with a Power BI-ready analytical view for reporting.

## Tools
- MySQL 8.0
- Power BI
- SQL

## SQL skills demonstrated
SELECT, WHERE, GROUP BY, ORDER BY, JOINs, SUM, COUNT, AVG, CASE statements, CTEs, CREATE VIEW.

## Business questions
- What are total sales, orders and customers?
- How does sales performance change month to month?
- Which states generate the most sales?
- Which product categories perform best?
- What is the average order value?
- What is the distribution of order statuses?
- What is the average delivery time?

## Dashboard plan
KPIs:
- Total Sales
- Total Orders
- Total Customers
- Average Order Value

Visuals:
- Monthly Sales Trend
- Sales by State
- Top 10 Product Categories
- Order Status Distribution
- Top 10 Products

## Dataset
Olist Brazilian E-Commerce Public Dataset.

## Resume description
**E-Commerce Sales Analysis | MySQL, Power BI, DAX**
- Analyzed multi-table e-commerce transaction data using MySQL to identify sales trends, customer behavior, product performance and order patterns.
- Used SQL joins, aggregations, CASE statements and CTEs to transform and analyze transactional data.
- Created a Power BI-ready SQL view for reporting across sales, customers, products and regional performance.
